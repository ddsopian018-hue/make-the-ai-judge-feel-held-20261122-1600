A carried-up-the-stairs relaxation text for make.fun's "Make the AI judge feel held" bounty ($50 in USDC). One memory of being carried at seven — two hands, a blanket that smells of rain and soap, a shoulder that stays warm — written so the short clauses do the slowing and the last line leaves the reader still resting in the curve of it. Nothing is commanded; the arms do the holding. The program writes the 266-character text to `entry.txt` and self-checks it against the 1–280 code-point gate before writing.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` to `/output` (or to `$MAKEFUN_OUTPUT_DIR` when set).
